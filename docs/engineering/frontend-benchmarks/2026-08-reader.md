The goal is not to copy any site's visual identity. InkFlow extracts established interaction patterns and applies its own restrained reading-first design.

## Patterns retained

1. **A book page needs one obvious primary action.** Start/continue reading is visually stronger than secondary metadata and tools.
2. **Catalog navigation must remain useful for very long works.** Search, order switching, clear chapter rows, and incremental rendering are required.
3. **The reader is content-first.** Navigation and settings stay compact; source selection, quality scores, crawler state, and Canonical internals are hidden from ordinary readers.
4. **Reader comfort is user-controlled.** Theme, font size, line height, and reading width are persistent preferences.
5. **Mobile is a first-class surface.** Main actions meet comfortable touch-target sizes and layouts collapse without hiding reading/navigation essentials.
6. **Status and failures are explicit.** Loading, empty library, missing catalog, and content-not-ready states receive purposeful UI instead of blank screens.

## InkFlow decisions

- Search → Book → Read is the shortest normal path.
- Book Detail shows status, author, description, chapter count, latest chapter, and prominent Start/Continue Read.
- TOC defaults to ordered chapters, supports title filtering and reverse order, and limits rendered rows in batches of 200.
- Reader supports system/light/warm/dark themes, 16–32 px text, 1.5–2.4 line height, and three content widths.
- Arrow-left/right keyboard navigation is available when focus is not inside an interactive control.
- Reader settings and last-read chapter stay local in Phase 1; account synchronization comes with the user product phase.
- UI does not surface source URLs, quality scores, content hashes, or crawler state to ordinary users.

## Acceptance focus

The first implementation must pass Node install, Nuxt typecheck, Vitest, production build, Docker runtime, API connectivity, mobile/desktop responsive review, keyboard focus review, and reader content-width review before it can be marked complete.
