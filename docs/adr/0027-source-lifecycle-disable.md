# ADR 0027：来源级停用与恢复

- 状态：Accepted for 1.0 Release Candidate
- 日期：2026-09-03
- 范围：Sources / Crawling / Operations / API

## 背景

来源能力健康只能停用单个 `(SourceId, Capability)`。运维需要在来源整体维护、合规或故障时停止所有入口，
同时保留来源规则、历史书目、正文和能力健康事实。

## 决策

1. `Source.IsEnabled` 持久化在 `sources.sources`，新来源默认为启用；迁移存量来源时也默认启用。
2. 来源级停用与恢复使用受 `SourceOperations` 保护、要求理由并追加审计的 API。停用不删除任何来源数据，
   恢复不重置能力健康状态。
3. 适配器工厂、直接地址解析、搜索发现、追更/健康可用性读取和规则 Worker 在执行前统一检查来源级开关；
   停用来源不得继续产生新的来源请求或被选作候选。
4. API 继续使用稳定的来源标识和最小状态响应，不返回凭据、规则载荷或任务变量。

## 后果

- 运维可以用一个来源级动作暂停全部来源执行，恢复后沿用原有能力健康与探针语义。
- 已存在的任务和历史数据仍可审计；正在执行的请求由现有租约/超时机制收敛，不在开关动作中强行删除。
- 更细的来源级计划窗口、自动恢复策略和批量启停仍需独立需求与审计设计。
